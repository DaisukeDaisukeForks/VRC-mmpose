フェーズ1: まず映像入力(m4 airでとった自撮り)
フェーズ2: カメラ映像をwebrtc(ローカル)で、何とかする。http処理層はcodexサンドボックスで防御する
フェーズ3: usbカメラ3台購入(Waveshare 4MP USBカメラ)

サーバー2(codexサンドボックス保護、オンラインサンドボックス): カメラ入力 or カメラ撮影、複数台対応
サーバー3(codexサンドボックス、オフラインサンドボックス): 遅延などの処理、統合etc
サーバー4(ネイティブ)
